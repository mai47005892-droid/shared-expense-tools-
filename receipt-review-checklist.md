# Itemized Receipt Review Checklist

Use this checklist to compare a receipt transcription with the source document before sharing or submitting an expense.

- Confirm that each entered line description corresponds to a visible source line.
- Check quantity and unit price before accepting a line total.
- Keep discounts, tax, service charges, and tips as separate entries when the source shows them separately.
- Compare the sum of entered lines and adjustments with the receipt total; investigate any difference instead of silently changing an entered amount.
- Record which participants share each line, rather than assuming that every line is shared by everyone.
- Save the source receipt alongside the exported allocation when the recipient's process requires it.

This is a transcription and review aid, not a statement of any employer, platform, tax authority, or reimbursement policy.
